# Unity Scripts

This folder contains the C# scripts used in the Unity digital twin simulation for hybrid social navigation of agricultural robots.

## Main Scripts

| Script | Purpose |
|---|---|
| `RobotSocialNavController.cs` | Main hybrid social navigation controller for the robot. |
| `RobotNavPatrol.cs` | NavMesh-based patrol/navigation behavior. |
| `UnityToMatlabTCP.cs` | Telemetry communication between Unity and MATLAB. |
| `RobotTelemetryPanel.cs` | Runtime visualization and telemetry monitoring panel. |
| `HumanWalker.cs` | Human agent walking behavior. |
| `HumanKinematics.cs` | Human motion and kinematic state estimation. |
| `SocialZoneDiana.cs` | Proxemic/social zone visualization or computation. |
| `TrajectoryTrail.cs` | Robot/human trajectory visualization. |

## Notes

Temporary scripts and backup folders are intentionally excluded from the repository.
